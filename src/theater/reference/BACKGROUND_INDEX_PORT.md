# Published background identity index

Reference: LevelUp 43a01721e8a02c87c955e175936f0ccf8dd97a81,
replay/map_background_index.go.

The in-memory index accepts filename keys and successfully decoded sidecars.
It counts loaded sidecars, collects claims from the key/module/mapNames, excludes
empty and generic map identities, and removes ambiguous identities into a sorted
claimant report. Duplicate claims from one key do not create ambiguity. Input
order does not affect the result.

Lookup first tries the exact normalized identity, then removes at most one of
_-_ranked, _heavies or _firefight. An ambiguous exact variant can still resolve
through its unambiguous base, matching the pinned source. A base cannot inherit
a variant. No guessed sentry-defense fallback is introduced.

Normalization collapses Unicode whitespace into underscores, applies Go simple
lowercase and removes one trailing _map. Rust's newer Unicode lowercase tables
change U+1C89, which the pinned Go runtime leaves unchanged. map_identity_unicode.rs
therefore contains the Go Unicode 15.0.0 simple lowercase mapping, generated by
TestHaloRustBackgroundIndex; the harness writes /private/tmp/halo-map-identity-unicode.rs.
When regenerating, format it with cargo fmt and compare it to the checked-in table.
The native oracle checks every Unicode scalar, including scalars Go leaves intact.

The oracle also contains 256 synthetic catalogs and the 109 published backgrounds:
7,408 queries, all identity/key counts and ambiguity reports. It exercises explicit
variants, unknown names, collisions, generic modules and fallback combinations.
The published catalog yields 236 resolvable identities.

Directory entry loading, skipped-file diagnostics, directory errors, metadata
signatures and cache invalidation are now implemented; see BACKGROUND_DIRECTORY_PORT.md.
Native keys retain arbitrary bytes through MapBackgroundKey and lookup_key.
Four additional pure-helper native cases check malformed/truncated UTF-8 keys
and raw ambiguity ordering independently of JSON display substitution.
Full film parity and the deferred architecture are unchanged.
