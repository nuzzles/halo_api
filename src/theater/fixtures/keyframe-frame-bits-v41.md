# Native keyframe frame overhead

Reference: LevelUp feat/v75, commit 43a01721e8a02c87c955e175936f0ccf8dd97a81.
Generator: ../reference/halo_rust_keyframe_frame_bits_test.go.txt, registered in
generate_oracles.py as TestHaloRustKeyframeFrameBits.

The 81 rows are the Cartesian product of nine signed 64-bit header and size-word
widths: minimum, negative 2^62, -1, 0, 1, 32, 108, positive 2^62, maximum.
Expected values come directly from native KeyframeProfile.CadreBits(), including
signed multiplication/addition overflow. They are not generated by Rust.
The default 108-bit header and two 32-bit words produce 172 bits. Default-state
and component bodies are excluded; this accessor cannot locate record endings.

native_keyframe_frame_bits checks every expected value before and after layout
JSON round-tripping on the host and in the actual wasm32 harness.
