# Signed inference entry oracle

Reference: LevelUp `43a01721e8a02c87c955e175936f0ccf8dd97a81`.
Generator: `reference/halo_rust_signed_inference_entry_test.go.txt`.

90 independent native cases combine three payloads (empty, a one-byte bound
Delta, and 32 zero bytes), optional 32-bit prefixes, and 15 starts from -65
through i64::MAX. Native results include 21 read panics and 69 successful calls.

The Rust comparison checks panic/success, final cursor, End indication, inferred
count, ordered records and retained binding state. WASM skips the 21 panic cases
because its panic strategy aborts. NativeFrameConfig::decode_inference_view has
no caller-owned cursor to restore on panic; the native panic cursor in this
fixture is not claimed as a checked Rust stateful inference contract.

Starts beyond the payload return an empty result with the unchanged native
cursor. A negative start can become valid after Skip(32), while a still-negative
source read retains native panic behavior. Padded-bit accounting saturates at
usize::MAX on narrow targets; end_bit remains the full i64 coordinate.

This matrix covers entry/header and empty bound-Delta behavior. It does not close
chain inference, arbitrary signed component continuation, raw resync, or recovery
mutation contracts. Expected data is generated by the pinned native parser,
not by Rust.
