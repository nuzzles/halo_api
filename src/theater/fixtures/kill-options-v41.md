# Native kill-source option normalization

Pinned reference: `43a01721e8a02c87c955e175936f0ccf8dd97a81`.
Generator: `../reference/halo_rust_kill_options_test.go.txt`, registered in
`generate_oracles.py` as `TestHaloRustKillOptions` in `internal/facts/killsource`.
It runs native `Options.normalize` on a 64-bit Go host; it does not execute
unbounded calibration/restart loops for extreme positive settings.

The 512 cases vary all booleans and three signed counts across negative values,
zero, ordinary positive counts, 32-bit boundaries, and i64 extremes. Rust compares
the complete normalized options and native defaults. It additionally verifies
caller values remain unchanged, JSON retains signed values, and normalization
is idempotent. All cases also run through the public API on wasm32.

`KillDecodeOptions` counts are now i64 rather than usize. Negative and zero
values select the same defaults as native: multiplicity 2, restarts 40, views 8.
Booleans remain exactly as supplied. Existing ordinary positive JSON is unchanged;
Rust callers with usize variables must explicitly convert them to signed counts.
The separately supplied map argument is unchanged.

Normalization retains the 64-bit native integer domain on every target. Execution
uses checked conversion to usize. On narrower targets a positive normalized count
outside the execution index domain yields typed `DecodeError::KillOption`, retaining
the field and value, after version/source validation and before preparation.
This is an explicit portability refusal, not a native recorded-data error; Go's
32-bit int API cannot receive those 64-bit values either. No saturation or wrap
is used, and huge positive counts are not silently replaced by defaults.

The captured full-result test `local_kill_source_decode_nonpositive_options`
uses i64::MIN multiplicity, -40 restarts and zero views against the same native
complete-result fixtures used by `local_kill_source_decode`. Those expectations
were generated by native Decode with its default configuration, independently
of Rust normalization.
