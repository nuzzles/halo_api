# Live biped mask publication

Reference: LevelUp feat/v75 `43a01721e8a02c87c955e175936f0ccf8dd97a81`.
Uses the existing native `record-mask-hook-v41.json.zlib` generated by
`reference/halo_rust_record_mask_hook_test.go.txt`; no expected data was changed.

The payload test now invokes a live RecordMask hook for all 256 cases / 6144
payloads and compares 2647 publications with native masks, full payload bytes,
and after-i0 bit offsets in order. The loaded-source test compares live callbacks
for 1280 selection cases: 9953 quantized-source and 9953 world-source publications.
These include disabled CaptureDirs, saturated quanta, duplicate selections,
unreadable chunks, isolation/speed filtering and dynamic orientation.

The per-record hook resolves the current receiver after companion decoding and
only after saturation rejection. Native mask index order is retained, without
replacing it by a bitmap. Packet bytes are borrowed for the callback. Retained
mask observations remain available independently of live callbacks. Publication
precedes source isolation and world speed filtering. Generic frame loops do not
publish this hook.

The observed payload, explicit-band quantized-source and explicit-band world-
source APIs accept the existing shared observer. Legacy APIs delegate without an
observer. This establishes mask publication, not a whole-Film context adapter,
independent semantic actions, or completion of the remaining parser parity gates.
