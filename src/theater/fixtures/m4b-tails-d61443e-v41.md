# Corrected native death-state and mobility tails

Reference: `d61443ef59268ad734355db8e9974f68db5ca6d0`.
Sources: `internal/grammar/components_object.go`, `components_biped_ability.go`,
`traverse.go:consumeSimStateHandleTail` and their primitive readers.
Generator: `reference/halo_rust_m4b_tails_test.go.txt`.

The independent Go fixture contains 384 death-state cases (128 each for archetypes
35, 40 and 22) and 1,152 mobility cases. Mobility covers three world axis/index
width profiles under quantized, full-precision and baseline-scope modes. Cases
cover all eight bit alignments and both constant-filled and deterministic random
inputs. Zero-filled mobility controls have their recorded active bit set to ensure
position widths are exercised. Every buffer is 128 bytes; truncation is outside
this fixture's coverage.

Each row keeps original bytes, context, native dispatch result and end position,
the next eight source bits, the complete native DeadState projection, mobility
hook flags and absolute-region histogram. Rust checks all those results, retains
every consumed bit as contiguous raw fields, and round-trips the output through
JSON. Both velocity-presence branches are explicitly checked. Expectations were
generated by actual Go dispatch before editing the Rust readers.

The recorded death-state byte at +0x1c gates the R(2)+3*R(14) velocity block.
A nonexistent earlier R(5) was removed; the scalar field is now named value_40
instead of the old value_40a/value_40b pair. Mobility positions use absolute world
widths with a distinct build-default region, rather than traversal widths. Raw
velocity/position codes remain uninterpreted; no replay state is constructed.

Validation passed: all 1,536 cases, all previous 3,584 M4b cases, runtime-assumption
retention and 14 synthetic native-entry regressions (17 tests total, 0.17s).
The full local corpus test was not selected (1 ignored). WASM, Clippy with warnings
denied, format/diff and 485 old-reference source hashes passed. Old corpus boundary
fixtures still require migration; this is not a full-film completeness claim.
