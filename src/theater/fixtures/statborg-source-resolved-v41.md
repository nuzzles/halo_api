The synthetic v41 source contains three component-2 death counter increments
for slot 10. Packet timestamps are 1, 2, 3 seconds; native source metadata sets
chunk number 44 and start time 500 ms, so resolved event times are 500, 1500,
2500 ms. Four cases use no death feed, an exact feed, a feed 151 ms late, and
an exact feed with a competing totals identity. Native SlotIdentityResolved
returns the expected identity map, source choice, denominators, conflicts and
ordered diagnostics. The equal-coverage case retains totals, as native does.

This fixture validates source timing and forwarding into the identity resolver;
it is not an independently annotated gameplay film or a semantic action golden.
Broader record-level identity cases are in statborg-identity-v41.json.zlib; source
metadata and truncation diagnostics are in the other statborg-source fixtures.
